# Kongle changes

## @TAG@

First published Kongle build with an MCUBoot OTA flow for PineTime.

### Highlights

- Run Kongle under the PineTime MCUBoot bootloader and build an application-only Nordic DFU ZIP.
- Receive a DFU image over BLE, stage it in external flash, verify it, and request a trial boot.
- Show update progress on the watch while Furu transfers the image.
- Provide a clock, BLE Current Time Service, and a visible connection indicator.

### Testing notes

- Trial firmware is **not confirmed automatically**. A reset can revert to the previous image. Manual confirmation is not implemented yet.
- The ZIP updates only the application; it does not install or update the bootloader.
- Test on a development watch with a recovery path before using a closed device.
