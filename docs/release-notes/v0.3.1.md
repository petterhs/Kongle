# Kongle @TAG@

Development firmware for testing battery use on a PineTime with a working
button. This combines the button interrupt power change from PR #16, DC/DC
regulation from PR #17, and battery reporting/history over BLE from PR #18.

- The button uses an interrupt instead of frequent polling while the screen is
  asleep.
- The nRF52832 requests its DC/DC regulator, as InfiniTime does.
- Furu can read battery voltage, charging state, and buffered history after a
  disconnect when using its battery-history development branch.

Flash-backed battery history remains disabled in this OTA build. It still
requires a development-board test with InfiniTime's LittleFS before it can be
used on closed watches. This image remains an MCUBoot trial until confirmed.
