# Kongle @TAG@

- Show battery estimates in 1% steps, with voltage and charging history in Furu.
- Wake to the clock with the button; a press from another page returns home,
  and a press on the clock sleeps. Long-hold reset remains available.
- Remove navigation instruction text from watch pages.
- Vibrate briefly for notifications, with a Vibration toggle in Settings.
- Reduce idle button polling and enable the PineTime DC/DC regulator.
- Fix OTA packages that InfiniTime accepted but did not activate.

Battery percentage still uses an approximate voltage curve. Settings are held
in RAM and reset on reboot. Flash-backed history remains experimental and is
not enabled in this release. Firmware starts as an unconfirmed MCUBoot trial.

Before promoting this candidate to stable, verify on a battery-powered watch:

- [ ] OTA from validated InfiniTime and confirmed Kongle; trial reset rollback.
- [ ] Button wake/home/sleep, swipe navigation, brightness, and no wake flicker.
- [ ] One short notification vibration while awake and asleep; Settings OFF
      suppresses it without dropping notifications.
- [ ] Furu shows voltage, charging transitions and 1% battery readings after a
      reconnect, including backfilled history.
- [ ] At least two days of normal use without unexpected resets or connection
      failures; note battery drain and any regressions.

After these pass, tag the tested commit as v0.3.1 to publish stable. If code
changes are needed, publish another RC and repeat the affected checks.
